TOLV twelve nights a year

Denmark first · Europe and world on request

Twelve nights.
Not three hundred.

Most people go to somewhere between five and ten concerts a year. So this does not hand you a listings page. Give it what you listen to and it returns a shortlist for the next twelve months, each one saying why it is there.

Your listening history is read on your own device. This is a static page. There is no server to send anything to, no account, no analytics and no third-party script. The file you drop in is opened by code running in your browser and is gone when you close the tab.

How it works

Every concert here was read from a venue's own website or programme feed, with the source and the date it was fetched recorded against it. Nothing is written by hand and nothing is generated.
